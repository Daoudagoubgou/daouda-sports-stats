# Daouda Sports Stats

Site statique responsive, prêt pour GitHub Pages.

## Publication gratuite sur GitHub Pages
1. Crée un dépôt GitHub public nommé `daouda-sports-stats`.
2. Envoie tous les fichiers de ce dossier à la racine du dépôt.
3. Ouvre **Settings → Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**.
5. Choisis la branche `main` et le dossier `/ (root)`, puis **Save**.
6. Après quelques minutes, GitHub affichera l'adresse du site dans cette page.

Les matchs et classements sont des exemples de démonstration. Pour les données réelles, il faudra brancher une API sportive et ne pas exposer une clé API privée dans le JavaScript public.
